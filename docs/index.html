WHY ENZO LIB

Everything a hub needs, nothing it doesn't

A dependency-free Luau library focused on a consistent look, a complete control set, and a loader that never goes stale.

Full window system

Windows, text-labeled sidebars, tabs and left/right groupboxes out of the box — resizable, draggable, and keybind-toggled.

Rich control set

Toggles, checkboxes, sliders, dropdowns, inputs, color pickers, key pickers, buttons and dependency boxes — all with live callbacks.

Always up to date

Load it straight from GitHub raw with one loadstring. No installers, no version pinning — you always run the latest source.

Floating status pill

A single draggable pill shows FPS, ping, avatar, username and the current place — collapsible, and toggles the window with one tap.

Lightweight by design

Single-file, dependency-free Luau. No external modules to fetch, no bloated init chain — it just runs.

Open source

The full source lives on GitHub. Read it, fork it, or ship your own hub on top of it — no license fees, ever.

SHOWCASE

Write a few lines, get a finished hub

Switch tabs to see how little code it takes to go from an empty script to a working window.

local Library = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/voidhub9-dotcom/enzo-lib/main/LibraryV2.lua.txt"
))()

local Window = Library:CreateWindow({
    Title = "Enzo Hub",
    Footer = "Enzo Lib",
    Icon = "rbxassetid://137471163061841",
    Size = UDim2.fromOffset(720, 600),
    Center = true,
    ToggleKeybind = Enum.KeyCode.RightControl,
})

local MainTab = Window:AddTab({ Name = "Main" })
local Features = MainTab:AddLeftGroupbox("Features")
Features:AddToggle("AutoFarm", {
    Text = "Auto farm",
    Default = false,
    Callback = function(enabled)
        print("Auto farm is now", enabled)
    end,
})

Features:AddSlider("WalkSpeed", {
    Text = "Walk speed",
    Default = 16, Min = 8, Max = 100,
    Suffix = " studs/s",
    Callback = function(value)
        print("Speed:", value)
    end,
})
Library:Notify({
    Title = "Enzo Hub",
    Description = "Auto farm enabled.",
    Time = 4,
})

Library:OnUnload(function()
    print("Enzo Lib unloaded cleanly")
end)
